## Proyecto destacado

### [MejorDicho!](https://mejor-dicho.com)

Plataforma para preservar y compartir la cultura popular colombiana (dichos, refranes y piropos), organizada por los 33 departamentos del país. Es un proyecto personal que diseñé, desarrollé y desplegué de punta a punta.

- **Búsqueda semántica con IA** sobre el contenido, integrando la API de Claude.
- **Mapa interactivo** de Colombia para explorar los dichos por región.
- **Capa social** con reacciones, comentarios y ranking.
- **PWA instalable**, desplegada con Nginx + Gunicorn y CI/CD.

`Next.js 14` `FastAPI` `PostgreSQL` `Claude API` `Nginx`
